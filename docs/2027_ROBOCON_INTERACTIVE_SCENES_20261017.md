# RoboCon 全场景键盘体验入口（2026-10-17）

在 `desktop` 的本机或远程图形桌面中运行：

```bash
cd /home/ldl/mybot_v3_stair_turn_rl
./run_robocon_scenes.sh --list
./run_robocon_scenes.sh
```

第二条打开 1–5 场景菜单。也可直接运行 `./run_robocon_scenes.sh slalom --autopilot`、`./run_robocon_scenes.sh beam`、`./run_robocon_scenes.sh low_frame --autopilot`、`./run_robocon_scenes.sh stairs`，或 `./run_robocon_scenes.sh map bridge`。窗口在 `desktop` 图形会话上显示；SSH 纯文字终端无法看见窗口，需同时连接该主机的远程桌面或使用其显示器。

## 键盘

| 场景 | 按键 |
| --- | --- |
| 共通 | `W/S` 前后，`A/D` 横移，`Q/E` 转向，`R` 复位；关窗或终端 `Ctrl+C` 退出。 |
| 绕桩、限高 | `P` 开/关自动路线；保持自动路线时按运动键可临时接管当前控制步。 |
| 单木桥 | `1` 强制行走，`2` 强制桥专家，`3` 恢复按位置自动切换；默认是自动。 |
| 历史完整地图 | `1`–`8` 切换八个出生位置；方向键、`U/O` 施加扰动。 |
| 三档直线台阶 | `1/2/3` 切换 8/10/12 cm 台阶入口。 |

窗口打印模型、位置、模式、跌倒及部分接触提示；提示按交互控制步采样，不是正式规则判定。正式成功率依照已有批量评测的 5 ms 物理子步和冻结判据。所有这些入口仅操控 MuJoCo 仿真，不连接实机电机。

若已有历史地图窗口，使用 `./run_mujoco.sh --stop` 关闭；在新菜单里选择其他场景会打开相应独立窗口。`runs/` 中的 JIT 权重保存在 desktop，本仓库公开 clone 不包含它们。
