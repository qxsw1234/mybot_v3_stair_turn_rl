# 当前 2027 规则场景现场键盘测试

`desktop` 图形桌面上的 MuJoCo 窗口已由 `run_robocon_2027_live.sh` 启动。这个入口仅加载当前已实现的 **2027 规则场景**，不调用历史完整地图。若窗口关闭，可重新运行：

```bash
cd /home/ldl/mybot_v3_stair_turn_rl
./run_robocon_2027_live.sh beam --duration 3600
```

若仅通过 SSH 登录，需要同时打开 `desktop` 的物理屏幕或远程桌面才能看到 MuJoCo 窗口。点击窗口后用键盘：

| 按键 | 作用 |
| --- | --- |
| `4` | 2027 规则尺寸绕桩：冻结通用模型 `059950`，六杆场景 |
| `5` | 2027 规则尺寸单木桥：通用 `059950` 入/出桥，桥专家 `060148` 过桥 |
| `6` | 2027 规则尺寸限高：Stage 1 研究模型 `064341`，0.29 m 净高框架 |
| `W/S`、`A/D`、`Q/E` | 前后、横移、转向 |
| `R` | 重置当前规则场景到入口 |
| `P` | 在绕桩/限高切换自动路线与键盘驾驶；键盘运动指令可临时覆盖自动路线 |
| `1/2/3` | 仅桥场景：强制普通行走、强制桥专家、恢复自动切换；默认自动 |

按 `4/5/6` 会关闭当前场景窗口并立即打开选定的另一个规则场景窗口。关窗即停止现场会话。终端日志位于 `/tmp/robocon_2027_live.log`；交互中的接触提示不是正式规则打分。

当前可加载的新版规则实体场景只有绕桩、单木桥、限高。2027 沟壑组合、高墙、梅花桩、轮胎阵和砖木坑尚未建成可验收的规则场景及对应专项策略，故本入口不会用旧图形或替代几何冒充新版测试。宽桥研究专家 `060148` 的规则桥双模式 100 回合为 94/100，未达 ≥95/100 晋级门槛；限高 `064341` 也未通过默认动力学跨引擎门槛。这些都是 MuJoCo 仿真观察，不连接实机电机。
