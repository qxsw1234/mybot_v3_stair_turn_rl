## 2. 如何计算完成度

不按迭代数、代码行数或最好的一段录像计算完成度。每个技能分别记录下面六个状态及证据链接；未通过的项保持未完成，不把它们简单折算为线性百分比。

| 状态 | 完成证据 |
|---|---|
| 几何与判据已验证 | 正确轨迹触发成功；碰桩、绕框、跳级、桥外落足等反例触发失败；重置清除事件状态 |
| 基线已测 | 明确模型、checkpoint、初态、种子、分母和失败类型的原始 JSON |
| 阶段仿真通过 | 100–200 回合留出测试达到该阶段门槛；训练阶段、尺寸和物理配置固定 |
| 正式仿真通过 | 规则尺寸、nominal/robust 分开，Isaac 每类至少 1000 回合；MuJoCo 100–200 回合且跨引擎差不超 10 个百分点 |
| 实机通过 | 完成吊架/低速/规则速度测试，保留视频和同步遥测，满足专项及统一要求 |
| 全场集成通过 | 不中途复位，完成入场、技能、恢复、再行走；180 s 内按规则记分 |

当前绕桩、桥、限高都有基线；限高还有阶段行为与诊断结果。**暂无技能完成全部六层验收。** 3×/4× 阻尼扫描归类为诊断，不能记入正式仿真通过。

### 固定评测协议

- Smoke：20–50 回合，检查代码、尺寸、失败原因和数值稳定性。
- 阶段筛选：200 回合，四个留出 seed 各 50 回合；例如 `2026101601..2026101604`，不得用于训练或挑动作。
- 正式 Isaac：nominal、robust 各至少 1000 回合，使用另一组 seed（例如 `2026101701..2026101704` 各 250 回合）。反复用来调参的 seed 不再叫最终留出集。
- 正式 MuJoCo：每个主要课程阶段 200 回合；绕桩还覆盖总计划的 3×30 次要求，200 回合中可分为 70/65/65，逐 seed 报告。
- 报成功数/总数、Wilson 95% 区间、各 seed 成绩、P50/P95 用时、失败类别、峰值力/冲量及基础运动回归。超时、出界、摔倒计失败；崩溃使该次运行无效，修复后重跑，不能删掉失败样本。
- 同批配对候选用相同初态清单；报告成功差及配对置信区间。更换模型参数或碰撞判据后，原基线必须重测。
- nominal 指参数固定，不等于随机鲁棒性。重复确定性同一初态不能声称覆盖多个独立场景；跨引擎采用同一显式初态清单，不能仅靠相同 RNG seed 假定两端一致。
- 正式 robust 组合至少涵盖初始位姿、几何 ±5%、标定不确定范围内的动力学、动作/观测延迟和短时 dropout，分别报告单因素和组合结果。

### 6.2 物理参数辨识

参考 PACE 的流程，先做仿真合成数据恢复实验，验证拟合器能找回已知参数。随后需要操作人员在吊架/保护条件下采集实机无框架的低幅目标轨迹；本计划不自动启动电机。

- 数据：时间戳、12关节目标/q/dq、IMU、反馈力矩或电流（注明是否估算）、电压/温度（若可用）、丢包；记录 kp/kd、减速比、关节符号和负载。
- 激励：静态保持、缓慢正弦/扫频，幅度和频率依据已测硬件限值制定；不从论文复制到 MyBot。至少覆盖不同姿态、速度和负载。
- 先按关节拟合执行器延迟、增益、被动阻尼/干摩擦；再用站立/低速行走验证足地接触。使用正参数边界和合理先验，防止用异常阻尼代偿错质量/惯量。
- 训练集/验证集按完整轨迹分离，至少三段留出；比较 q RMSE、dq RMSE、base高度/姿态、足地接触时序及可用的力矩误差。真实轨迹未到位时只标“仿真诊断”。

**拟合工程门槛（新增提案）**：相对原模型，留出 q/dq 综合误差至少降低30%，且任何单关节或机身姿态指标不得退化超过10%；若不能满足，检查数据时间对齐、齿比、摩擦语义与参数可辨识性，再设计激励。该相对指标只决定是否继续验证，不能证明物理安全或取代绝对误差/硬件限值。

**交付**：`identified_dynamics.yaml`（单位、有效区间、不确定度、数据hash）、`sysid_holdout_report.json`、更新后的 `hardware_capability.yaml`。无实机数据则该包保持“待实测”，不能填假限值。

## 8. P5：切换与实机，把技能变成可用系统

参考ABS的双策略架构，先用确定性的状态条件：`locomotion → align → expert → clear → recover → locomotion`。状态条件必须来自部署可获得的观测；单凭“走了几秒”不能判断后腿离框。

当前离框后保持1 s、目标混合0.5 s，在诊断模型下已有成功轨迹，但还没有证明进入专家和整条循环可靠。当前代码会重置策略/估计器历史，下一步须规定自动初始化/预热方式并单独测量；不允许人工清状态制造成功。

**实现与交付**

1. 两策略明确各自观测宽度、历史长度和动作中心；切换前后记录原始/实际目标跳变、关节反馈和饱和状态。参考0.5s插值，按标定的目标速率/力矩限值约束，不把同一个固定时间当全部场景的安全保证。
2. 验证正常离框、近失稳、入口偏航、观测短时丢失及过期的处理。观测失效应减速/站立；框内不能盲目切换到抬高站姿，需保持可通过姿态或进入已验证的安全状态。
3. 至少100次完整仿真切换循环，≥95次任务完成；切换引发摔倒为0，且无超过已测限值的目标/力矩。恢复时间与失败状态单独报告。
4. 人工实机流程：吊架/安全绳10次→低速20次→规则速度30次；完成专项门槛和统一≥27/30要求；保存视频、目标/反馈、IMU、温度/电流/力矩及失败原因。

**完成判据**：没有实机成功率则不得标记技能已完成。M2只有在至少两个项目满足规则级实机得分条件，并完成连续切换演示后才关闭；小样本模拟通过不计作两个得分项。

## 9. P6：后续技能与是否引入新算法

- **360 mm跨沟/300 mm高墙（M3）**：先测足端工作空间、可控跨步及落地负载；从小沟/低墙分级，使用Robot Parkour/Extreme Parkour的课程思想。完整沟壑的上行、跨沟、下行分别计数。先达到各子项Isaac≥95%、组合≥90%、MuJoCo组合≥85%，再实机；未达则保留已验收台阶/坡子项路线。
- **梅花桩/轮胎阵（M4）**：先检查77点高度图能否区分200 mm落足块和轮胎内孔；不足则新增局部crop或next-foot target/有效区mask。教师可用精确几何，部署输入必须来自实际传感器。轮胎必须建环形带孔碰撞模型；梅花桩需要逐块接触bitset，不能只看基座到达终点。
- **砖木坑（M4）**：先静态几何/摩擦/柔顺近似，再实物校准；按总计划至少20次规则尺寸实物测试，不能靠随机高度场成绩替代。
- **HIMLoco对照**：仅在模型和基础评测冻结后单开分支，三个训练seed、相同环境步数/训练预算与现有PPO-CSE对照。预设采纳条件：held-out鲁棒成功率提高≥5个百分点且配对/多seed证据支持，基础任务下降≤5个百分点，目标设备推理P95<20ms（50Hz控制预算）。不满足即保留现有算法；不得用更长训练时间声称算法胜出。
- **全场（M5）**：先把两个已验收技能串联；最终20个随机布局、两个启动区和多个顺序，每次180s，无人工复位，分别统计遥控/自主的有效分、罚分、P95耗时、失败恢复与放弃决策。返回分只有按规则满足条件才计入；独立障碍成功率不能直接相加成全场完成率。
